# Course Selection Page 🎓

A simple university course selection page made using HTML and CSS.

## About the Project

This project displays three university courses with their descriptions, durations, and registration buttons. It also includes a registration form where users can enter their personal details.

## Features

- Welcome banner
- Three full-width course cards
- Course descriptions and durations
- Learn More and Enroll Now buttons
- Registration form with name, email, and password fields
- Hover effects on buttons and cards
- Responsive layout

## Technologies Used

- HTML5
- CSS3

## CSS Concepts Practised

- Element, class, and ID selectors
- Attribute selectors
- Pseudo-classes (`:hover`, `:nth-child()`)
- Pseudo-elements (`::after`)
- Descendant and child selectors
- Sibling selectors
- CSS cascading and specificity
- Flexbox
- Media queries

## What I Learned

While making this project, I practised using different CSS selectors, working with Flexbox, styling forms, adding hover effects, and making a webpage responsive.
